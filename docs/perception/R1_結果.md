# R1:学習した認識器のテスト(2026-10-20)

学習:狭い通路の種 1・2(通路の範囲内 1,000 件)と種 4(ホール 400 件)。テストは学習に使っていない配置(別の乱数の種)。
規則 = 確認帯の点数 ≥ 16(元の規則。点をロボット中心から投影)、補正した規則 = 点を LiDAR の位置から投影。
各テストの詳細は `R1_テスト_aisle.md`・`R1_テスト_hall.md`・`R1_テスト_wide.md`・`R1_テスト_wide追加学習.md`。

## 分かったこと
1. 元の規則の誤登録は、LiDAR の取り付け位置(中心の 0.15 m 前)の補正漏れが原因。補正すると狭い通路では 0 件。
2. 規則は小さい障害物(停止ロボット)と遠い障害物を見逃す。点数のしきい値は、すぐ前の大きな障害物を前提にしている。
3. 学習は、学習と同じ種類の配置(通路内)では見逃し 10/149・誤登録 2/151 と高い精度。1 m 未満の障害物の見逃しは 0。
4. 学習は、学習にない条件で誤登録が増えた。通路幅が違うワールドで 98/451(22%)、ホールから見る場面で 28/126(22%)。
   幅の広いワールドのデータを学習に加えると 5/111(4.5%)に戻った。学習した認識は、使う配置・視点のデータがあれば強いが、それがないと規則より誤る。
5. 事前確認の視点(西ホール)では、学習の誤登録 7/56(13%)、見逃し 18/39(46%)。走行での事前確認に使うには信頼性が足りない。
