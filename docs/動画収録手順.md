# 動画の収録手順(場面ごとの操作と、実行するコマンド)

構成は Project の `claude/動画構成案.md`(目安 2:52)。録画は Mac の画面収録(手動)で行う。
**ロボットの操作の扱い:** 場面 2〜6 は、人の入力(指示の文、指差し、ジェスチャー)そのものを見せる場面なので手動で行う。場面 4 のパレット配置と、テイク間のリセットはスクリプトで自動化した。場面 7(2 台)は自動実行の様子を録画する。

## 0. 画面とターミナルの配置

| 名前 | 場所 | 用途 |
|---|---|---|
| 【N1】 | ブラウザの noVNC(単一: http://localhost:6080)のターミナル 1 | シミュレータと Nav2 の起動 |
| 【N2】 | 同 ターミナル 2 | Gazebo の画面(`ign gazebo -g`)。録画では左半分に置く |
| 【T1 指示】 | Mac のターミナル | `llm_commander.py`(指示の入力とログ)。録画では右半分に置く |
| 【T2 操作】 | Mac のターミナル | リセット、パレットの配置 |
| 【T3 カメラ】 | Mac のターミナル | `pointing_cam.py`(指差し)・`gesture_teleop.py`(ジェスチャー) |

- T1〜T3 は、最初に次を実行してプロンプトを短くし、ユーザー名・ホスト名を映さない(bash): `PS1='$ '`
- T1・T3 は仮想環境を有効にする: `cd ~/Desktop/pai_final/host && source .venv/bin/activate`
- T2 は `cd ~/Desktop/pai_final/host && source .venv/bin/activate`(スクリプトを使うため T1 と同じ)
- 文字は大きく(`Cmd + プラス` を 3〜4 回)。録画は `Cmd + Shift + 5` →「選択部分を収録」で、タイトルバー(ユーザー名が出ることがある)を範囲から外す。

## 2. テイク間のリセット(各場面の前に毎回)

| 場所 | コマンド |
|---|---|
| T1 | `Ctrl+C`(コマンダーを止める。通行止めの記憶が消える) |
| T2 | `./video_reset.sh`(パレット撤去、箱を初期位置へ、ロボットを入荷口へ、コストマップ消去)。場面 5 だけは `./video_reset.sh south`(南通路にパレットを置いた状態にする) |

うまく戻らない場合: N1 で `Ctrl+C` → `bash ~/ros2_ws/stop_nav.sh` → `bash ~/ros2_ws/run_nav.sh cargo:=true`、N2 で `ign gazebo -g` を開き直す(1〜2 分)。
