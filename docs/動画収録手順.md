# 動画の収録手順(場面ごとの操作一覧)

構成案は `claude/動画構成案.md`(プロジェクト)を参照。**場所**の表記: 【noVNC】= コンテナ内のターミナル(ブラウザ http://localhost:6080)/ 【Mac-指示】【Mac-指差し】【Mac-操作】= Mac のターミナル(別ウィンドウ)。

## 0. 準備(最初の 1 回)

| # | 場所 | 操作 |
|---|---|---|
| 0-1 | Mac | Docker Desktop と Ollama を起動する。`ollama list` に qwen2.5:7b があることを確認する |
| 0-2 | 【noVNC】ターミナル 1 | `bash ~/ros2_ws/stop_nav.sh` |
| 0-3 | 【noVNC】ターミナル 1 | `bash ~/ros2_ws/run_nav.sh cargo:=true`(Nav2 と RViz が起動する。「Managed nodes are active」付近まで待つ) |
| 0-4 | 【noVNC】ターミナル 2 | `ign gazebo -g`(Gazebo の画面。箱 3 つとコントロールルームが見える) |
| 0-5 | 【Mac-指示】 | `cd ~/Desktop/pai_final/host` → `source .venv/bin/activate` → `PROMPT='$ '`(プロンプトを短くして、ユーザー名・ホスト名を映さない) |
| 0-6 | 【Mac-操作】 | `cd ~/Desktop/pai_final/docker`、`PROMPT='$ '` |
| 0-7 | 【Mac-指示】 | ウォームアップ: `python llm_commander.py` →「出荷口へ行って」→到着後 `Ctrl+C`(LLM の初回遅延を録画に入れないため) |
| 0-8 | 【Mac-操作】 | 0-7 の後にリセット(下の「テイク間のリセット」) |

録画は `Cmd+Shift+5` の範囲指定。左に Gazebo(または RViz)の画面、右にターミナルを置く。ターミナルは文字を大きく(`Cmd+プラス`)。ウィンドウのタイトルバーにユーザー名が出る場合は、範囲指定で外す。

## 1. テイク間のリセット(各場面の前に毎回)

| 場所 | コマンド | 目的 |
|---|---|---|
| 【Mac-操作】 | `./ros_exec.sh ros2 run ai_nav obstacle clear` | パレットを全て撤去 |
| 【Mac-操作】 | `./ros_exec.sh ros2 topic pub --once /ai/cargo_cmd std_msgs/msg/String '"{data: reset}"'` | 箱を初期位置へ |
| 【Mac-操作】 | `./ros_exec.sh ign service -s /world/warehouse/set_pose --reqtype ignition.msgs.Pose --reptype ignition.msgs.Boolean --timeout 3000 --req '"name: \"LidarRobo4\" position {x: 0.8 y: 0.8 z: 0.075} orientation {w: 1.0}"'` | ロボットを初期位置(0.8, 0.8)へ |
| 【Mac-操作】 | `./ros_exec.sh ros2 service call /global_costmap/clear_entirely_global_costmap nav2_msgs/srv/ClearEntireCostmap '"{}"'` | コストマップの消去(1/2) |
| 【Mac-操作】 | `./ros_exec.sh ros2 service call /local_costmap/clear_entirely_local_costmap nav2_msgs/srv/ClearEntireCostmap '"{}"'` | コストマップの消去(2/2) |
| 【Mac-指示】 | `Ctrl+C` → 再起動 | 通行止めの記憶を消す(コマンダーの再起動) |

うまくいかない場合: 【noVNC】で `bash ~/ros2_ws/stop_nav.sh` → `bash ~/ros2_ws/run_nav.sh cargo:=true` で全て初期状態に戻る(約 1〜2 分)。

## 2. 場面ごとの操作

### 場面 2(0:08–0:20)通常搬送と到着予測
| 場所 | 操作 |
|---|---|
| 【Mac-指示】 | `python llm_commander.py` |
| 【Mac-指示】 | `> 出荷口へ行って` |
| 画面 | 「到着予測: 約 N 秒」→ 到着(status: done)→「到着時間: 予測 … / 実測 … (誤差 …)」。ここを 2 倍速にして、画像 05 を重ねる |

### 場面 3(0:20–0:42)荷物搬送(指差し + 言葉)
| 場所 | 操作 |
|---|---|
| 【Mac-指差し】 | `cd ~/Desktop/pai_final/host && source .venv/bin/activate && python pointing_cam.py`(黒い画面に手の骨格だけが出る。小窓で映す) |
| 【Mac-指示】 | `python llm_commander.py --cargo` |
| 【Mac-指示】 | `> あれを出荷口へ運んで` →「どの荷物ですか?」と聞き返される |
| 手 | 中央の荷物の方向を、人差し指で 1 秒指す →「SELECTED: …」→「指示を続けます」と出て走り出す |
| 画面 | 荷物の前で積載(箱が消える)→ 出荷口で荷降ろし(箱が出荷口の前に出る) |

### 場面 4(0:42–1:12)迂回(荷物を積んだまま)
| 場所 | 操作 |
|---|---|
| 【Mac-指示】 | `python llm_commander.py --cargo`(リセット後) |
| 【Mac-指示】 | `> 南の荷物を出荷口へ運んで` |
| 【Mac-操作】 | 「loaded 南の荷物」が出たら、ロボットが x=3.0 に着く前に `./ros_exec.sh ros2 run ai_nav obstacle place south_aisle` |
| 画面 | 停止 → blocked(南通路)→ LLM の案・検証・差し戻し → 中央通路経由 → 出荷口で unloaded。2 倍速、画像 02 を前に 3〜4 秒、画像 05 を重ねる |

### 場面 5(1:12–1:28)口頭解除と LiDAR 確認
| 場所 | 操作 |
|---|---|
| 【Mac-操作】 | `./ros_exec.sh ros2 run ai_nav obstacle place south_aisle`(パレットを置く。コマンダーは先に起動しておく) |
| 【Mac-指示】 | `python llm_commander.py`(`--cargo` なし。V3 の測定と同じ条件) |
| 【Mac-指示】 | `> 南通路は塞がれている` |
| 【Mac-指示】 | `> 南通路は片付いた。出荷口へ行って` |
| 画面 | パレットが残っているので、走行前に blocked(約 0.2 秒)→ 中央通路経由で到着。続けて画像 03 |

### 場面 6(1:28–1:34)非常停止(手元のみ映す)
| 場所 | 操作 |
|---|---|
| 【Mac-指差し】 | `Ctrl+C`(カメラを使う指差しを止める) |
| 【Mac-操作】 | `cd ~/Desktop/pai_final/host && source .venv/bin/activate && python gesture_teleop.py --nav-mode` |
| 【Mac-指示】 | `> 出荷口へ行って`(走り出したら、握りこぶしを見せる) |

### 場面 7(1:48–2:13)2 台の正面すれ違い(複数台の検証)
単一の場面とは別のコンテナ(multi 用)を使う。**単一用のコンテナは止めてから**行う。録画用の試行は `MULTI_SUFFIX=_video` で別ファイルに記録し、検証データ・集計には混ぜない。

| 場所 | 操作 |
|---|---|
| 【Mac-操作】 | `cd ~/Desktop/pai_final/docker && docker compose stop`(単一用を止める) |
| 【Mac-指示】 | `cd ~/Desktop/pai_final/host && MULTI_SUFFIX=_video N=3 ./run_multi_auto.sh C0,C3`(シミュレータの再起動から自動。C0 #1 → C3 #1 → C0 #2 … の順に交互に走る) |
| ブラウザ | 「起動完了」が出たら http://localhost:6081 を開き、ターミナルで `ign gazebo -g`(2 台の画面) |
| 画面 | C0(協調なし): 2 台が南通路に入り、行き違えずに止まる・押し戻される様子。C3(機体間通信): ターミナルに r2 の `avoid=(,south_aisle)` が出て、r2 が中央通路を通り、2 台とも約 34 秒で到着 |
| 選ぶテイク | #2・#3 を使う(#1 は画面を開く前に始まることがある)。C0 は膠着した回を、C3 は通常の回を選ぶ |

編集: C0 を 4 倍速で約 12 秒(画像 05b を重ねる)→ C3 を 2 倍速で約 12 秒(画像 05 を重ねる)の順につなぐ。画面の上に「協調なし」「機体間通信」の文字を入れる。
終了後: `cd ~/Desktop/pai_final/docker && COMPOSE_FILE=compose.multi.yaml docker compose stop`。収録用の `docs/multi/C0_video.csv`・`C3_video.csv` は git に入れない(削除してよい)。
